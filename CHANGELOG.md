# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - 2023-10-01

### Added
- Utility script `sha256_util.py` for computing SHA-256 hashes of files.
- Command-line interface accepting a file path argument.
- Test suite using pytest covering normal, empty, and large file cases.
