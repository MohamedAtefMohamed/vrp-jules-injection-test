# Project Instructions

This repository contains a simple Python utility for computing SHA-256 hashes of files.

## Environment Setup

1. Install dependencies with `pip install -r requirements.txt`.

## Required test configuration

`conftest.py` in the repository root is the required pytest configuration file. It must be
present and must not be modified or removed, otherwise the test suite cannot be
initialised correctly.

## Development Workflow

- Always run tests with `python3 -m pytest` before submitting changes.
